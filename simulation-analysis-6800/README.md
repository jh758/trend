# 6,800건 통합 시뮬레이션 분석자료

combined_analysis.html을 브라우저에서 열어 사용합니다. 기존 면적3,400건 + 면적4배3,400건이며, 기존3,400건 분석자료는 별도 원래 위치에 보존되어 있습니다.

- 동일 축척 레이아웃 비교: 집중배치7구역의 기존/4배 레이아웃을 같은10m격자로 표시. 이미지내장으로단독HTML에서도표시. 원본PNG저장가능.
- 차트 아래 배치 및 작업 조건 필터: 카트/AMR 각각 센터 면적 기준 체크박스(기존 면적/면적4배) 제공. 다른 조건과 같이 독립 선택. 상단 면적 선택으로 두 카드의 면적을 일괄 설정.
- 센터 면적 필터: 두 면적/기존/4배. 산점도·완료시간 순위·전체 지표·용량/왕복 비교·구역 배정도에 적용.
- 동일 조건 면적 비교:3,400쌍. 방식/배치별 평균 완료시간 막대와 쌍별 평균 증감률 표. 별도 area_comparison_pairs.csv 제공.
- 경제성: 사용자가 선택한 카트 인원·완료시간으로 모든 AMR을 고정 비교. 면적·배치에 따른 자동 교체 및 카트 비교 범위 선택 없음. 매칭OFF전담1명, 월야근수당, 작업일수, 빨간 강조, 앞쪽 레이어·넓은 클릭영역·연결 말풍선 유지.
- 카트80건, 추종/자율분산/구역방식 각2,240건.36박스는두면적합계960건.
- 히트맵: 두 면적의 입력 수요는 같고 면적 선택은 실제 치수와10m축척에 반영. 실제 정지/이동/혼잡 결과가 아님.
- 속도 비교40쌍, 구역방식 비교면적/배치별560쌍, 용량 비교면적별480조건군. 고정 요약과 조건 필터 적용 범위를 화면에 표기.
